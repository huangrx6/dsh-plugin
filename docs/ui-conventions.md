# 插件 UI 约定：PC / H5 两层设计

> 每个插件的界面按 **Desktop + H5 两套**设计，PC 为默认层，H5 是显式的
> 手机层；**每个插件各自拥有并维护自己的 H5 媒体查询**，不依赖其他插件
> 或工作区壳的任何兜底（例如壳层的 `overflow-x: hidden` 只是最后一道保险，
> 不是设计目标）。

## 两层结构

每个 `styles.ts` 里都有一条插件自己的 H5 层：

```css
/* ── Desktop（默认，无媒体查询）────────────────────────────── */
.… { /* 桌面版式 */ }

/* ── H5（≤767px）──────────────────────────────────────────── */
@media (max-width: 767px) {
  .… { /* 手机版式：改尺寸、重排、换行、堆叠 */ }
}

/* ── 小屏手机（≤480px，可选）───────────────────────────────── */
@media (max-width: 480px) { … }
```

- **H5 的覆盖只允许写在 `@media (max-width: 767px)` 内**；桌面规则保持不动。
- 大屏还要考虑内容区被工作区限宽到 ~960px，深浅两层都要在限宽下成立。

## 设计基准与规则

评审/实现时用 **375px（H5）** 与 **1440px（PC）** 两个宽度过一遍。

1. **触控目标**：H5 下按钮/开关/行高 ≥ 36px（建议 40px），间距别贴死。
2. **工具栏**：H5 下源分段条、搜索框各自独占整行（`flex-basis: 100%` /
   `width: 100%`），图标按钮组一行放不下就 `flex-wrap` 换行，不硬挤。
3. **卡片网格**：轨道不得超容器 —— `minmax(min(190px, 100%), 1fr)`，
   H5 内边距收窄（卡片 12–14px，容器 8px）。
4. **长文本**：可能超宽的字串一律 `overflow-wrap: anywhere`（URL、命令、
   会话 id、等宽参数等）；flex/grid 子项补 `min-width: 0` 链。
5. **table / pre / 代码块 / JSON 树**：`max-width: 100%` + `overflow-x: auto`，
   不要让内容撑宽页面。
6. **弹框**：H5 下 `width: 100%`（± 12px 遮罩内边距 = `calc(100vw - 24px)`）；
   内部左右分栏（如 文件树+预览、master-detail）在 H5 改纵向堆叠并各自限高滚动。
7. **分段控件**：H5 轨道内横向滚动（`overflow-x: auto` + 隐藏滚动条），
   或换行铺满，不得溢出。
8. **行内徽章/标签/等宽版本号**：flex `flex-wrap` + `min-width: 0`，不撑破行。

## 验收

- 任何布局改动：PC 与 H5 各看一眼；
- H5 页无横向滚动（`body` 不出横向滚动条）；
- `pnpm run check` 全过。
